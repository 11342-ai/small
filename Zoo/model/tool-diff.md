# 文件比对工具（file_diff）

> 位置：`internal/tool/builtin`（file_diff.go）+ `tool_permissions.go`（权限）+ `register.go`（注册）+ `main.go`（base 提示词）+ `internal/workflow/workflows/pdf.md`（核对步）
> 状态：已实现（2026-09-02），单测（含 -race）与 go vet、gofmt 通过；本文件为唯一技术索引
> 关联：`tool-extend.md`（A 档无痛扩展承诺）；`tool.md`（声明/执行/注册约定）；`policy.md`（Pass 权限）；`tool-fs.md`（路径约束、大小上限、.env 防护）；`pdf-workflow.md`（整理链路，本工具为它补内容核对手段）

## 1. 结论先行

- 新增单个内置只读工具 `file_diff`：比对两个文本文件，输出两级报告（内容块定位 + 块内字/词细标），细标始终回显原文。
- 敏感度可按类降低：`ignore` 数组枚举 `space`/`punct`/`symbol`。归一化只作用于判定与定位，报告回显原文；纯格式差异折叠为尾部计数，不展开刷屏。
- 落点属 tool-extend.md A 档无痛扩展：tool 模块零改动、builtin 追加一个元素、权限 Pass、Deps 复用 File 配置（nil 退化不注册）、组合根不改一行。
- 纯 stdlib 自实现两级 diff（无第三方 diff 库、不调 git diff 外部进程）——对齐项目零依赖倾向与红线 6（builtin 生产代码只 import tool/memory/policy）。
- 辅助小改动：main.go base 提示词补工具说明；workflows/pdf.md 落盘后加一步可选核对（原版 vs 整理产物，带 ignore 判内容无实质丢失才汇报完成）。

## 2. 需求理解（为什么做）

场景由来：Zoo/pdf工具对比效果/ 下成对出现的"原版 vs 经过 agent 处理"文档，以及 pdf 工作流的清洗/整理链路，暴露一个缺口——整理产物相对原文到底改了什么、有没有丢内容，目前只能人肉比对，而仓库没有文本比对工具。

用户三个诉求拆解：

1. 文件 vs 文件比对：两个路径即可比。路径语义与 file_read 对齐（相对工作区根，或工作区外显式绝对路径）。
2. 差异要落到"部分字/段落"：中文文档按行 diff 会被换行位置、段落切分灌满噪音；需要在段落（内容块）粒度定位增删改，再对改动块做字/词级细标，避免"整行不同"的粗糙报告。
3. 敏感度可调：OCR/解析/排版噪声（逐字空格、分页残留、标点/特殊符号差异）在"整理后 vs 原版"核对应判为格式差异而非实质内容变化；但代码比对、精校场景又要全敏感。故做成按类可选忽略。

设计原则：

- 归一化只用于判定与定位；细标回显原文，可对回文件定位，模型不用脑补归一化后的内容在原文哪里。
- 判实质相同（归一化后相等）的块归入"仅格式差异"，尾部折叠计数 + 少量一行示例。
- 移动/重排检测 v1 不做：同一文本仅切分/顺序不同，若两侧归一化拼接相等，一次性归类"排版/切分差异"提示，不做移动追踪。

## 3. 工具契约

### 3.1 Spec 与参数

名称 `file_diff`。描述面向模型，中文一段话，须交代：比对两个文本文件的内容差异；默认逐项展示（标点/空白/特殊字符的差异也算），需要只看实质内容差异时传 `ignore`；路径规则同 file_read（工作区内，或用户明确要求的工作区外路径；.env 与系统敏感目录拒绝）；单文件超过 10MB 拒绝。

参数 JSON Schema：

```json
{
  "type": "object",
  "properties": {
    "file_a": {"type": "string", "description": "被比对文件 A（相对工作区根或显式绝对路径）"},
    "file_b": {"type": "string", "description": "被比对文件 B（相对工作区根或显式绝对路径）"},
    "ignore": {
      "type": "array",
      "items": {"type": "string", "enum": ["space", "punct", "symbol"]},
      "description": "忽略的差异类别（可组合）：space 空白、punct 标点、symbol 特殊字符。缺省空 = 全敏感，逐项展示"
    },
    "limit": {"type": "integer", "description": "细标明细最多条数，缺省 10，0 = 不限；统计恒为全量"}
  },
  "required": ["file_a", "file_b"]
}
```

### 3.2 忽略类别定义

以 Unicode 属性归类，stdlib `unicode` 即可，无需词表：

- space：空白与排版符（Unicode Z* 及 \t\r\n\f 等控制空白）。
- punct：标点（Unicode P*，覆盖中文全角标点、引号括号）。
- symbol：符号/特殊字符（Unicode S*，及 No 类圈码如 ①② 等非十进制数字符号）。
- 文字恒保留，永不被忽略：word 字符 = Unicode L*（含 CJK）+ Nd（数字，含全角数字）+ 下划线。

三类以 Unicode 属性划分，语义透明可预期，模型按需组合；差异展示时被忽略的字符不参与比对，但两侧上下文仍按原文回显。

### 3.3 归一化变换

`n(text, ignore)` = 剔除 ignore 对应类别后的字符序列。判同、块指纹、对齐全部基于 n 后的序列；原文保留用于回显。注意：空行（块边界）不受 ignore 影响——space 只折叠块内换行/缩进为空白并剔除，不合并块。

## 4. 比对流程（两级）

1. 读文件：两侧各自过既有检查——大小 ≤ 10MB（对齐 file_read 上限，超限拒绝并提示 doc_search 定位思路）、.env 前缀与敏感目录黑名单拒绝、含 NUL 字节按二进制拒绝。读入后按行保留行号。
2. 切块：以空行分隔连续行 → 内容块。语言中立（md/正文/代码一致）；标题/列表若被空行包围自然成块，未被空行隔离的相邻条目并入同一块，由其内部细标处理。
3. 块级定位：两侧块按 n(块) 指纹做 Myers 对齐（相同块靠指纹 O(1) 判同，长文档同质部分不耗 LCS），得到相同块与改动区（两侧各一段未对齐块序列）。
4. 区级细标，对每个改动区：
   - 若两侧 n(拼接文本) 相等 → 归类"排版/切分差异"，折叠计数，不细标（对应重排/空行位置变化）。
   - 否则两侧块按顺序两两配对细标，多余单侧块判纯增/删。每对做 token 级细 diff：token = CJK 逐字 + 拉丁/数字连写 + 其他单字；被 ignore 的类别在比对时剔除，回显仍带原文上下文。
   - 细 diff 上限：两侧块均 ≤ 4096 rune 才执行（防 O(N·M) 爆炸）；超限整块降级为段落级条目 + 提示"改动面大，建议 file_read 窗口细读"。
5. 组装报告（§5）。

复杂度：块级 Myers O((N+M)·D)，D 为差异块数；指纹相同块零成本；内存常驻，10MB 内可控。

## 5. 报告格式（模型消费，中文纯文本）

统计头：A/B 路径、各自总行数；实质差异计数（增/删/改块数）、仅格式差异计数（空白/标点/特殊字符/排版，折叠）。

明细至多 `limit` 条（缺省 10），每条形如：

```text
[改] A:第 45-46 行 ↔ B:第 33-34 行（A 第 3 段）
A: …处三年以下有期徒刑『拘役』并处罚金…
B: …处三年以下有期徒刑并处罚金…
```

约定：定位 = 两侧行号区间 + 块序；『』内是最小差异片段（A 侧为删除内容、B 侧为新增内容），两侧各带约 6 字原文上下文，省略处加 …；单侧无变化的簇只出另一侧行（纯插入只出 B 行，纯删除只出 A 行）。多簇散点在一段内时逐簇成对展示，超 6 簇计数收尾。纯删/增块直接贴块文本（超 300 rune 截断）。类型标 `[增]/[删]/[改]`，图例（『』语义）在首个 [改] 前打一行。

尾部：未展完给"另有 k 处实质差异未展开（可传 limit 加大）"，对齐 file_read 续读提示惯例。总输出仍过 truncateOutput（8000 rune）双保险。

折叠样例（至多 5 条一行）：`[格式] A:第 12 行 ↔ B:第 9 行（仅忽略类差异）`、`[排版] A:第 1-2 行 ↔ B:第 1-3 行（切分/重排，内容一致）`，其余计数。

无实质差异：报告"无实质内容差异；格式/排版差异 N 处（空白/标点/符号/切分，已折叠）"，可去掉对应 ignore 逐项查看。

## 6. 边界与安全（对齐 tool-fs.md）

- 只读 Pass：权限表登记 Pass，无确认交互。
- 路径：resolveReadPath（工作区内放行、工作区外显式路径过敏感目录黑名单，fail-closed）。
- 敏感文件：.env 前缀拒绝（比对结果可能泄露机密）。
- 幂等无状态：纯函数 + 读文件，无副作用，不写任何状态。
- 红线：不 exec 外部 diff 命令（无进程/shell 依赖，防命令注入面，也符合 imports_test 固化）。
