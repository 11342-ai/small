**摘要**：在万物互联的大背景下，微信小程序这个轻量级的应用在教育中的作用与日俱增，为教育行业带来新的发展机遇和可能性。为顺应互联网+发展趋势，设计开发一款基于微信小程序的高校场地预约平台，可实现预约教室、预约实验室、预约会议室，并一键通知上课学生补课信息、参会人员参会信息等功能，为高校教室提供实用便利的教室、实验室预约管理平台。基于小程序的教室预约平台设计使用了 MINA 微信小程序开发框架，通过 MySQL 数据库管理数据。所开发的小程序能够满足预约教室、实验室的使用需求，避免了以往线下预约教室、实验室、会议室的繁琐操作。

**关键词**：微信小程序；MINA框架；场地预约；MySQL

## 0 引言

随着中国数字化经济的迅猛发展，各行各业的数字化转型带来了大量的数字化场景需要，带动了中国在互联网+、计算机硬件、云计算以及人工智能方面跑出更快的创新速度。与此同时，越来越多的应用如雨后春笋般被开发出来，为互联网时代的人们提供了便捷的工具，为人们的学习和娱乐提供便利。数字化技术之一的微信小程序已经渗透到各行各业，包揽了人们衣食住行的方方面面。据数据统计，截至 2023 年 1 月，微信小程序的日活用户已经突破 4.4 亿，覆盖超过 200 个行业，正在成为互联网经济中的新星［1］。

由于微信小程序具备"无须安装、触手可及、用完即走、无须卸载"的特性，基于小程序的高校场地预约平台在教学中的应用得到了快速发展，基于微信平台底层支撑，微信小程序可以在手机、平板等移动设备上运行。因此，具有使用不受时间和地点限制，运行简单快捷［2］。本文设计了基于小程序的教室预约平台。高校场地预约平台系统使用了 MINA 微信小程序开发框架，采用了 SpringBoot 的 Java 后端框架处理数据，通过 MySQL 数据库管理数据。用户可以通过微信小程序查看场地预约情况，申请预约场地，场地管理员进行审批，审批通过的场地申请通过微信订阅通知的形式发送给场地申请人。

## 1 系统设计

根据功能需求，将高校场地预约平台系统划分为前端、后端。前端主要实现信息展示与用户交互，后端主要通过操作数据库来实现数据的持久化。

### 1.1 前端 MINA 框架

场地预约平台系统以微信小程序 MINA 框架为依托，采用 MVC 的运行机制，使视图层与应用逻辑层代码相分离。①视图层由 WXML 与 WXSS 编写。可以将逻辑层的数据反映到视图来响应给用户，也可以转发用户的交互事件给逻辑层。在视图层中 WXML 主要用于描述页面的结构，WXSS 可以结合 WXML，美化页面。②应用逻辑层是 MINA 框架的服务中心，也被称之为 APP Service。其使用 JavaScript 来进行数据处理并完成视图层的事件监听。小程序中的各个页面可以通过 APP Service 实现数据管理、网络通信、生命周期管理和页面路由。

### 1.2 后端 SpringBoot 框架

场地预约平台系统采用 SpringBoot 框架实现了 Java 后台，它简化了基于 Spring 的应用开发，通过少量的代码就能创建一个独立的、产品级别的 Spring 应用［3］；使用 MySQL 数据库来完成数据从用户到数据库的数据访问和操作。使用 SpringBoot 可以简化配置文件，以更简单的方式整合第三方技术，可以快速创建独立运行的 Spring 项目。

## 2 系统功能设计

根据对本校教室管理流程的调查分析，本系统对高校场地预约的几个常用功能场景进行了设计，包括预约教室、预约实验室、预约会议室，一键通知上课学生补课信息、一键通知参会人员参会信息等。本文对高校教室预约最常见的教室预约、教室管理、日程提醒进行着重介绍。

### 2.1 教室预约

该子系统实现对学校教室的管理，通过调查发现，目前针对教室的使用是查看教室课表，该教室非课表期间的使用按照"先到先得"的方式，该方式容易造成使用时间冲突的问题。因此教室预约部分的设计按照"先预订，后使用"的原则，使用该教室的教师只能预约非上课时间段。教室的预约请求需要教室负责人进行审核。教师在预约教室时不仅可以看到其他老师已经审核通过的预约记录，也可以看到其他老师未审核状态的预约记录，避免了预约时间的冲突，也减少了教室负责人的手工记录预约的工作。

当教室预约信息被教室负责人审核通过后，根据教师申请教室时所填写的班级信息，会自动发送补课、班会等微信消息通知到每个学生，避免了教师找教室、通知学生补课等复杂的操作，也避免了群消息传达不到位的情况。教室预约流程如图 1 所示。

**图 1 教室预约流程图**：

```
预约教室
  ├─ 选择用途：座谈会 / 补课、班会、实验课
  ├─ 审核：
  │    ├─ 座谈会 → 选择参会教师
  │    └─ 补课、班会、实验课 → 选择选课学生班级
  ├─ 管理员审核，规则是"先到先得"
  └─ 审核通过 → 微信消息的形式通知申请人及参会人相关信息
```

### 2.2 教室管理

教室管理部分采用现有数据，通过教务系统导出的场地课表，以上传 Excel 表的形式将教室数据以及教室课表数据批量添加到系统内。由于教室数据比较庞大，为了便于教室负责人进行教室管理，教室管理部分既可以在微信小程序内进行操作，也可以在后台管理系统内进行操作。教室负责人主要进行教室管理、教室预约审核。针对不同教室的不同配置，也可以在系统内通过教室管理编辑教室信息，还可通过 Canvas 画布技术添加教室布局，并上传该真实的环境信息，使得教师不需要现场查看即可判断该教室是否可以满足教师的使用需求。

### 2.3 日程提醒

已经通过审核的预约教室申请，会自动通过微信订阅消息发送到预约教室的教师、通过班级号绑定该预约教室信息的学生，除此之外，该微信小程序的首页即为日程列表，如果有待办事项，即按照时间顺序进行显示，方便直观。当该上课状态由待上课转为已完成状态，该事项即从日程列表删除，若要查看历史日程，则可以在"我的历史"Tab 页面进行查看。

## 3 系统主要功能实现

### 3.1 注册功能实现

本系统的用户数据由教务系统导出的学生列表或者符合批量操作的表格数据进行批量导入，导入成功的用户，在用户首次登录时需要按照身份证号、手机号、手机号验证码进行登录，随后设置修改密码。未被管理员导入信息的用户则提示其"该信息未被录入，请联系管理员"。用户验证功能在 login 模块完成，包含 login.wxml、login.wxss、login.js 和 login.json 四个文件。为了确保学校数据的安全性，只有被管理员导入信息的人员才能进行信息验证并登录系统。为此采用了手机号验证、密码安全性验证的方式：

①手机号验证，要求用户注册时提供真实的手机号码，并通过短信验证码验证其身份，从而有效防止用户使用虚假或无效的手机号码注册，确保用户的真实性；

②密码安全性验证，要求用户设置密码时遵循高强度密码的规则，设置密码需要至少包含 8 个字符，并应包含大小写字母、数字和特殊符号，增强了账户安全性。

用户仅需在首次登录时需要验证，后期可以通过其设置的密码进行登录。

### 3.2 教室预约功能实现

用户登录后，即可看到日程页面，在日程页面点击"+"号，即可进入到教室申请的页面。教室预约申请功能在预约 reservation 模块完成，该模块包含了 reservation.wxml、reservation.wxss、reservation.json 和 reservation.js 四个文件，用户在教室预约页面上选择预约的场地类别为预约教室、并选择预约时间，随后进行查找，系统会返回该时间段内原课表没有课、也没有已审核通过的预约申请的教室。但已提交预约申请但教室仍会出现在搜索的结果列表中，但会有明显的黄色字体提示教师，该教室在该时间段内已有预约信息但尚未通过审核。这样既避免了教室申请教室操作冗余冲突，也为未审核的预约请求提供了可以调节的空间。

在可预约的教室后点击"预约"按钮，即可触发事件，激活 bindtap 中的事件绑定，调用 reservation.js 的 addReservation 方法，调出填写教室预约申请单弹窗，如果教师选择的教室使用事项是补课，则必须选择上课学生班级，这样不仅可以一键通知学生补课申请，也可以在教师预约时判断该班级在该时间段是否有其他教师已经申请了预约信息，如已申请预约信息，则该选项为灰色，不可点击。并提示教师，该时间段内学生已有上课信息，建议其修改时间段后再进行预约。

预约教室申请单提交后，即进入待审批状态，当教室负责人审批通过后，教室预约成功的信息包含教室地址、使用教室的教师姓名、使用教室事由、使用教室日期、使用教室时间等通过微信消息通知到教师和学生。实现效果（日程页面）如图 2 所示。

## 4 数据库设计（MySQL）

数据库采用最流行的 MySQL 数据库管理和存储数据，根据需求将教室信息、实验室信息、用户信息、角色信息、预约信息等存储在数据库中。

主要数据表包括系统管理员表、管理员角色表、用户表、场地表、预约信息等等表格。系统管理员表主要用于存储的是系统管理员的用户名、密码、手机号、姓名、性别、电子邮箱等信息。管理员角色表记录系统管理员角色、所属模块、操作模块的权限等信息。用户表中，用户 id 是主键，进行手机号验证后设置的密码采用了 MD5 信息摘要算法的加密方式进行存储。

预约信息表记录场地预约的各种状态，主要有预约单号和审核状态（0：待审核；1：已审核；2：正在使用；3：已使用；-1：审核未通过，已退回）；预约单号共由三部分组成，一是场地预约单提交的时间，二是加密密钥，三是同时间段内同时提交订单时对订单的排序序号；预约单表还包含预约人的用户 id、预约人姓名、预约类型、预约开始时间、预约结束时间、场地地点、使用事由、上课学生班级号、预约人联系方式等信息。

在传统模式下，小程序之间的数据交换是通过从小程序端向 Web 服务器端发送数据请求来进行的。Web 服务器端向数据库提交 SQL 命令以获得返回结果，然后向小程序端发送数据响应。此模式需要历经来自 Web 服务器端和数据库端的两层数据响应。当并发用户数量高时，会对整个程序的性能产生一定的影响。本文采用了一种数据缓存模式下的数据交互方法［4］。Web 服务器预先将数据库中的数据读取到数据缓存中。当它接收到来自小程序的数据请求时，它会从数据缓存中查询数据以获取数据响应。由于内存查询的速度远高于数据库查询，因此提高了数据响应能力。

## 5 结语

该系统以 MINA 框架为基础，采用了 SpringBoot 框架实现 Java 后台，使用了 MySQL 数据库，来完成数据从用户到数据库的数据访问和操作。以此打造了一个方便快捷的场地预约平台，实现了"无须安装、触手可及、用完即走、无须卸载"的特性。在高校教室、实验室、会议室的预约使用带来了极大的便利，使得预约信息清晰可见，避免了手工操作所带来的繁琐操作，做到了不需要现场办理，只需线上申请即可使用会议室，并通过一键提醒教师和学生，即可发送预约成功请求，并将该预约信息添加到对应用户的日程中。给教室和学生在高校的工作和生活带来了极大便利，打破了传统现场联系预约的局限性，而且比 Web 平台更独立、更安全，实现了不同受众用户的最大化。微信小程序作为轻型应用代表着今后移动 APP 的发展方向，这种轻型应用虽然不会替代所有的独立 APP，但也会是未来移动互联网应用的主要形式［5］，使用基于微信小程序的场地预约平台系统，不仅提高了教师和教室负责人工作效率和服务质量，而且对未来教学工作的开展具有很好的促进作用。

**Design of a college venue reservation platform based on mini programs**

Tian Ruifen\*, Cheng Yanyan

(School of Information Engineering, Zhengzhou Institute of Industrial Application Technology, Zhengzhou 451150, China)

**Abstract**: In the context of the Internet of Things, the role of WeChat mini programs as lightweight applications in education is increasing day by day, bringing new development opportunities and possibilities to the education industry. In order to comply with the development trend of Internet plus, a university venue reservation platform based on WeChat applet is designed and developed, which can realize the functions of classroom reservation, laboratory reservation, conference room reservation, and one click notification of make⁃up information of students in class, information of participants in the meeting, etc., providing a practical and convenient platform for classroom and laboratory reservation management for university teaching rooms. The design of a classroom reservation platform based on mini programs uses the MINA WeChat mini program development framework and manages data through the MySQL database. The project ran stably and the developed mini program can meet the needs of classroom and laboratory reservation, avoiding the tedious operation of offline booking of classrooms, laboratories, and conference rooms in the past.

**Keywords**: WeChat mini program; MINA framework; venue reservation; MySQL
