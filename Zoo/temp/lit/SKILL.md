# 文档解析使用指南（doc_parse / doc_read / doc_clean）

本指南是 doc_* 工具的使用说明：何时用、标准流程、已知噪声与修复指引。工具已封装 lit 命令为固定参数，不要裸调 lit。

## 何时使用

- 用户要求读文档（PDF/Word/PPT/Excel/图片）、提取内容、查某个值 → doc_parse。
- 文档格式判断：born-digital PDF（有文字层，绝大多数报告/文书）默认够快；扫描件/图片才需要 ocr=true。

## 标准流程（每步一个工具，别跳步）

1. doc_parse <source 绝对路径>：解析落缓存，返回路径 + 摘要。
2. doc_clean <产物路径>：清洗确定性噪声（分页符/页码/水印重复/空行）。
3. doc_read <产物路径> [offset] [limit]：窗口化细读，控制上下文成本。
4. 整理：先询问用户「在原文件直接整理还是新开文件」，确认后
   用 propose_file_write（确认后落地）或 file_write（每步确认）落盘。

## 参数速查

- doc_parse：source（必填，任意绝对路径）；pages（如 1-5,10）；ocr（默认 false，扫描件 true）；format（默认 text，json 仅当需要版式坐标）。
- doc_read：path（doc_parse 返回的路径）；offset（1-based）；limit（行数，读到文件尾缺省）。
- doc_clean：path（缓存产物路径，仅限缓存目录内）。

## 已知噪声与修复（实测样例）

### 规则已自动处理（doc_clean 管）

- 分页符横线：独立成行的 `----`。
- 页码残留：独立成行的「第 N 页」；横线页码残留（`－70－`、`- 70 -`、`——12——`）。
- 水印重复字眼：同一行内紧邻重复词组（如「人民法院案例库 人民法院案例库」），相邻完全相同的行。
- 连续空行折叠。
- CJK 字间空格压缩：逐字拆分修复（「第 一 百 四 十 一 条」→「第一百四十一条」）；数字/英文间空格不动。

### AI 整理阶段需手动修复（doc_clean 不管，语义问题）

整理流程（pdf-workflow.md §4）：doc_clean 预处理后，按下面清单修复语义问题。

- 段落合并（改进点1）：被分页符/页码打断的段落拼接；行尾无句读（。！？；）且语义连续 → 与下行合并；逐字空格已清，重点恢复断行成段。
- 词间距恢复：连续中文按语义恢复自然短语间距（「第一百四十一条 生产、销售假药的」），中文标点后不加空格。
- 换行粘连（异常点1）：列表项被挤成一行，如原 markdown 的
  - aaa / - bbb / - ccc 经 pdf 往返后变 aaabbbcccddd。
  修复：按语义断句点恢复换行与列表标记。
- 列表换行错位（异常点2）：列表项之间被插空行或换行位置漂移。
  修复：恢复列表结构与紧凑排布。
- 数字/日期空格拆分（异常点4）：4.4亿→「4.4 亿」、2024年7月10日→「2024 7 10 / 年 月 日」。
  修复：按语境合并（计数单位、年月日、百分比、金额）。
- 双栏大空白（知网格式）：正文被中间大空白划成两栏，标题/引用格式也失效。
  修复：先左栏后右栏重排为连续段落，恢复标题层级。

### 大 PDF 分批流程（pdf-workflow.md §4）

大 PDF（产物大/解析慢）分片处理，别一次全量：

1. doc_parse pages 分片：每次约 50 页（如 1-50 / 51-100 / 101-150…），每片独立缓存文件。
2. 每片 doc_clean + doc_read 细读 + 按上面清单整理出片段。
3. 全部片整理完后按序拼接成完整文档，再询问用户原位整理 or 新开文件落盘。
4. 轮次充足（max_tool_rounds 缺省 20，config.yml 可调），但每轮仍按需读窗口、别整灌。

### 修复时的格式约束

- 只修噪声，不改内容事实（数字、日期、金额、人名原样保留）。
- 合并/拆分仅在有把握时做，拿不准的保留原文。
- 修复后检查：无孤立分页符/页码残留、无重复水印、段落连续、列表结构完整、数字连续、词间距自然。

## 纪律（重要）

- parse once：同源同内容重复解析自动命中缓存，不要重复 doc_parse。
- 窗口读：doc_read 用 limit 控制量，别一次读完大文件。
- json 格式只在需要版式坐标时用，产物更大仍按窗口读。
- 不要裸调 lit 命令（exec 白名单也没有 lit）。
- doc_parse 返回摘要先判断相关性，不相关就别往下读。

## 环境要求

- 依赖 lit（npm i -g @llamaindex/liteparse）。缺失时 doc_parse 返回安装指引，把指引告诉用户即可，不要尝试自动安装。
- Office 文档需本机 LibreOffice，图片需 ImageMagick（lit 自动转换）。
